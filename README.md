# Data_Visualization
This project explores Airbnb data to understand listing behavior, customer reviews, and availability trends. The dataset was prepared in Excel and visualized using Tableau to create an interactive dashboard that highlights pricing patterns, review activity, and booking availability over time.

The analysis is based on three main data sources: listings, reviews, and calendar information. Together, they provide insight into how prices vary, how guests interact through reviews, and how availability changes across different periods.

The Tableau dashboard allows users to explore the data interactively using filters such as location, room type, and date. This makes it easier to identify trends, compare listings, and gain practical insights from the data.

Overall, this project demonstrates skills in data preparation, exploratory analysis, and visual storytelling with Tableau, and is intended for learning and portfolio purposes.
